# Seiza for Windows 0.9.2

This patch fixes installation on Windows machines without the Visual C++
Redistributable installed. Download the MSI and install it normally; the native
runtime is included in Seiza's DLLs.

## Installer fix

The released 0.9.1 installer could fail with error 1723 (exit code 1603) in
`NotifyShellAssociations`, because its embedded native DLL required
`VCRUNTIME140.dll`. The same missing prerequisite could prevent the viewer or
Explorer handlers from loading.

All three Rust DLLs now statically link the C runtime, including their native
dependencies. This also covers the Shell action loaded from Windows Installer's
temporary directory during installation and removal. The MSI stays self-contained
and supports offline installation.

Setup also recovers from failed 0.9.1 installations. That version could finish
removing its files and registration, then report an error from the same Shell
action. The upgrade now checks that every previous product was actually removed
before continuing. A genuine uninstall failure still stops setup before new
files are installed.

Native builds and both MSI packaging paths audit normal and delayed DLL imports.
CI and production releases also load the shipped DLLs and the action extracted
from the actual MSI while VC runtime resolution is deliberately blocked. The
installation smoke test requires Seiza's real main window to open, so a loader
error dialog cannot count as a successful launch.

## Validation

The original installer reproduced error 1723 in a clean, offline Windows Sandbox
without the VC runtime. The fixed installer installed, opened the Seiza main
window and uninstalled successfully in a fresh Sandbox; the VC runtime remained
absent afterward. The old native DLLs fail the blocked-runtime loader test and
the rebuilt DLLs, including the MSI's embedded action, pass it.

All 868 managed tests and 32 native Shell-provider tests passed locally. Normal
and skip-publish MSI builds completed with zero warnings or errors, and all 281
published binaries passed the runtime dependency audit. CI also passed the full
native/managed/Windows suites and installer checks on the fix PR.

This release retains the Seiza 0.48.0 native dependencies and existing imaging,
stacking and calibration behavior. The signed MSI, updater feed and checksums are
published by the production tag workflow.
