# Seiza for Windows 0.8.0

Create parallax videos from astronomy images in a native Windows workspace.
This release uses published Seiza 0.25.1, stacking 0.27.0 and parallax 0.2.1
crates, with no vendored renderer or crate patches.

[Download the Windows x64 installer](https://github.com/theatrus/seiza-win/releases/download/v0.8.0/seiza-0.8.0-windows-x86_64.msi)
· [SHA-256 checksums](https://github.com/theatrus/seiza-win/releases/download/v0.8.0/SHA256SUMS.txt)

## Parallax video

- Open an image, then choose **Parallax video…** from the toolbar's More
  options menu. The independent workspace keeps a private image snapshot and
  any existing plate solution; original files are never modified.
- Import aligned starless and unscreened-stars layers, or use a separately
  installed RC-Astro CLI (`rc-astro.exe`) licensed for StarXTerminator.
  No third-party separator is bundled or installed. Manual-layer solving uses
  the selected stars even when the viewer contains the starless image.
- Adjust star and background depth, camera travel, spin, labels and output
  settings. Pick destinations directly on the source image, generate and
  edit multi-stop tours, and save or load portable tour itinerary JSON.
- Download the focused offline star/object distance datasets from Catalog
  Settings. Object distances are validated against their matching object
  catalog; invalid environment overrides show the path that needs repair.
- Preview the camera move and export silent H.264 or HEVC MP4 through Windows
  Media Foundation. H.264 is broadly available; HEVC requires an installed
  encoder. Unsupported encoders report an actionable error without replacing
  an existing movie.
- Custom thin or tall output sizes keep the same framing in preview and
  export. Independent parallax windows keep application services alive after
  the original viewer closes.

See the [parallax workflow and safety guide](https://github.com/theatrus/seiza-win/blob/v0.8.0/docs/PARALLAX-VIDEO.md)
for layer requirements, controls and export limits.

## Distribution

The self-contained Windows x64 MSI and all five first-party application
binaries are Authenticode signed by **StackFoundry LLC**. Release checks verify
the signed files sealed inside the installer, including the new offline
distance adapter. The in-app updater verifies the signed update feed and
installer. Windows 11 24H2 or newer is required.
