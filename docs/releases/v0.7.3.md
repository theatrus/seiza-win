# Seiza for Windows 0.7.3

This point release opens more XISF files, in the app and in File Explorer. It
moves to the published Seiza 0.18.16 core, whose XISF reader follows the XISF
1.0 Revision 1 specification published in September 2026.

[Download the Windows x64 installer](https://github.com/theatrus/seiza-win/releases/download/v0.7.3/seiza-0.7.3-windows-x86_64.msi)
· [SHA-256 checksums](https://github.com/theatrus/seiza-win/releases/download/v0.7.3/SHA256SUMS.txt)

## XISF files

- XISF images whose pixels are stored inside the file header now open. PixInsight
  stores small images this way.
- Images stored pixel by pixel, rather than channel by channel, now open.
- Compressed data split into subblocks now opens, including subblocks that
  PixInsight stores uncompressed because compression would not shrink them.
- CIELab images open in color, converted to RGB with the image's color space.
- When a file holds several images, its main image opens even if another image
  in the file uses a format Seiza cannot read.
- Explorer thumbnails and Preview Pane images use the same reader, so these
  files preview in Explorer too.

The reader was checked against PixInsight 1.9.5: it reads every sample format,
compression codec and checksum PixInsight writes.

## Core and distribution

- Bundle the published Seiza 0.18.16 C ABI.
- The x64 MSI and its first-party binaries are Authenticode signed by
  **StackFoundry LLC**. The in-app updater verifies both the signed update feed
  and the installer signature in that feed.
