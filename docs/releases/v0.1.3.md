# Seiza for Windows 0.1.3

The first release delivered through Seiza's signed in-app updater.

## Changes

- Fixed the installer's selected-by-default **Launch Seiza** action. Clicking
  Finish now opens the installed application in the signed-in user's desktop
  session.
- Replaced the directory-relative executable custom action with WiX's
  purpose-built unelevated shell action and the fully resolved installed path.

## Update from 0.1.2

Seiza 0.1.2 checks for this release automatically after startup. To check
immediately, use **More > Check for updates** or **Settings > Check now**.
Seiza verifies the signed Sparkle feed and MSI before opening Windows Installer.
The app then exits, Windows requests administrator approval for the all-users
upgrade, and the installer retains the selected **Launch Seiza** option on its
final page.

## Install directly

Download `seiza-0.1.3-windows-x86_64.msi` and compare it with the value in
`SHA256SUMS.txt`. The installer requires Windows 11 24H2 or newer on x64 and
administrator approval because it installs for every user.

This preview is not yet Authenticode-signed, so Windows may display an
unknown-publisher warning. Sparkle's Ed25519 signatures independently protect
the update feed and downloaded installer. The MSI includes .NET 10, Windows
App SDK/WinUI, Win2D, and the Seiza Rust core; it does not download another
runtime during installation or first launch.

## Still in progress
