# Seiza for Windows 0.10.0

AI noise reduction is now a visible step in **Processing**, alongside background
correction, deconvolution and stretching. The open FITS or XISF image is used
automatically; the recommended model and runtime install when needed.

- Drag a preview rectangle to evaluate an area of interest. Inference runs only
  on that area, while the preview keeps the full image's processing context.
- Adjust grain and mottle strengths without rerunning cached inference.
  Residual caching is bounded to two entries and 384 MiB; larger full-image
  results retain their latest blended file without retaining the residual.
- Save changes applies the AI step to the full image. Undo, redo, copied settings,
  image export and parallax rendering preserve the processing recipe.
- Save linear AI FITS exports noise reduction before the remaining processing.
- Model downloads, updates, imports and device settings remain available in the
  processing panel's expandable advanced section.

Uses Seiza 0.56.0 with shared Rust, C ABI and Python preview-region support.
