# Seiza for Windows 0.8.7

This release adds image collections from TXT and CSV path lists, including
PixInsight SubframeSelector exports, and fixes the sidebar's source label for
collections spanning multiple directories.

## Open an image list

- Choose **Open image list** in the toolbar and select a `.txt` or `.csv` file.
  Its images share one browser, thumbnail rail, navigation and stacking collection.
- TXT files accept one path per line with optional surrounding quotes. CSV files
  recognize `path`, `filepath`, `file_path`, `file` or `filename` headers, ignoring
  case and surrounding whitespace. Headerless CSV uses the first column.
- Relative paths resolve beside the list file; absolute paths are also accepted.
  Quote CSV paths containing commas. Quoted fields and escaped quotes are supported.
- Leading settings rows before a recognized CSV header are ignored, including
  PixInsight SubframeSelector metadata. All listed images are included regardless
  of their Approved flag; opening a list does not apply a quality filter.
- Duplicate paths appear once. Missing, invalid or unsupported entries are
  counted in the sidebar. Empty lists and malformed CSV produce an error.

## Correct collection labels

The browser shows the source list filename, image count and any skipped entries.
Its tooltip gives the complete list path. It no longer presents the first
image's directory as the root of a collection from several directories.

The directory label and **Include subfolders** control apply to folder browsing;
they are hidden for image lists. Navigating images and changing grouping retain
the list's source identity.

See the [image-list formats and examples](https://github.com/theatrus/seiza-win/blob/v0.8.7/README.md#image-viewing-and-folder-review).

## Validation and dependencies

Validation includes **814 managed tests**, **96 Windows graphics/codec tests**
(four optional-input skips), and the native Rust suites. Interactive validation
opened a SubframeSelector-style CSV spanning two folders, deduplicated a repeated
image, reported a missing entry, and preserved the list label through navigation
and regrouping.

Native dependencies are unchanged from 0.8.6: Seiza/C ABI **0.44.2**, stacking
**0.51.2**, parallax **0.19.2**, satellites **0.22.2** and image-io **0.11.0**.
The production workflow signs the application and installer as **StackFoundry
LLC**, verifies the packaged signatures, smoke-tests installation and launch,
and publishes the signed updater feed with SHA-256 checksums.
