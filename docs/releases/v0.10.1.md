# Seiza for Windows 0.10.1

Processing settings now return when you reopen a FITS or XISF image. **Save
changes** writes a small `.seiza.json` sidecar beside the source, preserving AI
noise reduction, background correction, deconvolution, ordered stretch stages
and color handling. Paste, undo and redo update the saved recipe too. Previews
and Cancel leave it unchanged; the source image is never rewritten.

Keep the sidecar with its image when moving or renaming files. For example,
`M31.xisf` uses `M31.xisf.seiza.json`. An unreadable recipe opens with default
processing and a warning. Recipes requiring unavailable models or devices also
fall back to defaults without changing the sidecar. A failed save keeps the applied settings in memory
and explains that they could not be remembered.

- AI noise reduction settings now collapse, with a separate card and clearer
  divisions between processing steps.
- Fixed a Windows UI crash when turning noise reduction off and back on.
- Choose **Selected rectangle** or **Full image** for AI previews. The full
  image option disables rectangle controls and retains your previous rectangle.
- **Show rectangle outline** controls just the outline, without rerunning AI.

Uses Seiza 0.56.0.
