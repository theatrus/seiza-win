# Seiza for Windows 0.1.1

A point release that cleans up installation alongside the Seiza CLI and
updates the Rust core.

## Changes

- The app now installs as **Seiza for Windows** in Apps & Features. The Seiza
  CLI installer (from the main seiza repository) used to share the plain
  "Seiza" name, so a machine with both showed two identical entries. The CLI
  is now "Seiza CLI" and the app is "Seiza for Windows". Existing installs
  upgrade in place; the Start menu shortcut and file associations are
  unchanged.
- Updated the Seiza Rust core to 0.12.2, which brings the N.I.N.A.-exact u16
  stretch family and float auto-stretch (seiza-stretch 0.2.0) to every stretch
  path in the app.

## Install

Download `seiza-0.1.1-windows-x86_64.msi` and compare it with the published
SHA-256 checksum. The installer requires Windows 11 24H2 or newer on x64 and
administrator approval because it installs for every user.

This preview is not yet code-signed, so Windows may display an
unknown-publisher warning. The MSI includes .NET 10, Windows App SDK/WinUI,
Win2D, and the Seiza Rust core; it does not download another runtime during
installation or first launch.

## Still in progress

Multiple document windows, 16-bit PNG/TIFF export, Explorer Preview/thumbnail
integration, ARM64, and production code signing remain planned work.
