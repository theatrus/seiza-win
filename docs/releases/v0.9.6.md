# Seiza for Windows 0.9.6

AI Models continues to download and install Seiza's recommended noise model
automatically. Use **Preview center** to compare the center tiles, adjust
**Grain reduction** and **Mottle reduction**, then **Save full FITS…** for the
complete image. Installed models work offline. The bundled DirectML runtime
remains the default on supported Windows GPUs.

The welcome screen now points to the Stack toolbar button.

When a fallback CPU runtime is needed, Seiza now handles its installation and
repair through the shared core API. Downloads use verified sources and include
the VC++ DLLs needed on clean Windows systems. A failed or cancelled install
preserves the previous runtime. Advanced runtime overrides remain supported.

Uses Seiza/C ABI 0.55.0, including the mosaic panel-background corrections from
0.54.0 and aperture-photometry memory improvements. The release pipeline now
checks actual noise-model inference, blending, FITS export, missing coverage
and cancellation against the packaged runtime before publishing the installer.
