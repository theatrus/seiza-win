# Seiza for Windows 0.7.5

This point release exposes the new stacking options in the published Seiza
0.19.0 core and stacking 0.20.0.

[Download the Windows x64 installer](https://github.com/theatrus/seiza-win/releases/download/v0.7.5/seiza-0.7.5-windows-x86_64.msi)
· [SHA-256 checksums](https://github.com/theatrus/seiza-win/releases/download/v0.7.5/SHA256SUMS.txt)

## Stacking controls

- Choose the reference automatically from the selected raw lights, independently
  for each directory filter group. Seiza's native scorer chooses a sharp frame
  with a flat sky. Live stacking can score compatible existing lights at
  startup; an empty folder starts with its first stable light, and resuming
  retains the saved reference.
- Directory and live stacking offer similarity, affine, and quadratic
  registration. Affine/quadratic fit distortion after the initial star match;
  too few matched stars retain the similarity transform.
- Local background normalization uses one photometric gain per channel with
  tiled background offsets, reducing frame-edge seams without independent
  tile gains.
- Inverse-noise-variance frame weighting favors cleaner frames. Its minimum
  and maximum weights are adjustable; equal weighting remains available.
- Choose bilinear or Lanczos-3 resampling. Lanczos-3 is sharper and costs more
  processing time.
- Bayer inputs offer VNG, MHC, or bilinear demosaicing, or Bayer drizzle.
  VNG preserves star color; MHC is sharper but can ring around small stars;
  bilinear is fastest. Drizzle needs enough dithered frames to fill each color.
- Optional hot/dead pixel suppression applies before demosaicing, with
  independently adjustable low/high sigma thresholds.
- Existing option defaults remain unchanged. New nondefault settings belong
  to saved-session identity, so another recipe cannot silently resume a stack.
- Transient removal shows all three native passes. Local background
  normalization uses an integrated reference. Native scratch caching reduces repeated
  frame preparation; source files are not modified.

and the installer signature in that feed.
