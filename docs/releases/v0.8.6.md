# Seiza for Windows 0.8.6

This release adds GPU stacking controls, expanded mosaic workflows, large-image
viewing, and narrowband, continuum and RGB star tools. It uses the published
Seiza/C ABI 0.44.2 and includes the Windows image-shortcut browsing fix.

## GPU stacking and mosaic planning

- Choose automatic GPU use or CPU-only processing in **Settings > Stacking
  performance**. Set a persistent **GPU planning budget (MiB)**, with 0 meaning
  automatic. The budget guides accumulator placement and reintegration bands;
  it is a soft planning budget, not a hard allocation ceiling.
- Batch stacking, live stacking and sensor-defect learning use the selected
  policy. Resuming a compatible checkpoint applies the current GPU mode and
  budget while preserving accumulated frames. Active runs keep their settings.
- Solve and group selected lights by sky coordinates, review whole panels or
  individual exposures, and build an expanded mosaic or retain dithered edges.
  Canvas memory limits, overlap controls and planning notes remain visible.
- Expanded canvases reject Local normalization before starting; use Local
  background, Global or None. Updated native processing includes preparation
  ahead of planning and parallel blind-registration candidate scoring.

## Images larger than 16,384 pixels

- Open mosaics wider or taller than a single GPU bitmap can support. The viewer
  uses virtual GPU tiles at full resolution, with fit, zoom, pan and registered
  sky overlays.
- Clipboard and image exports avoid oversized GPU surfaces. Overlay exports
  render in tiles for both 8-bit and 16-bit output. CPU memory, managed-array
  sizes and output-format limits still apply.
- A borderless, proportionally enlarged **20,480 × 11,520** M31 diagnostic image
  loaded and solved interactively in **1.17 s**, with **456 matched stars** and
  **0.468 arcsec RMS**. This is a resampled validation image, not a claim of
  additional astronomical resolution or a general mosaic performance benchmark.

## Narrowband, continuum and RGB stars

Open **Color stacking > Narrowband, continuum and RGB stars…**. Choose sources,
build and review a preview, then save FITS or XISF. Optional processing settings
start collapsed, and changing inputs or settings disables stale saving.

- Compose HOO or SHO display palettes with midtone balance, shadow protection,
  channel boosts, optional star exclusion, broadband structure and green
  reduction.
- Analyze stellar continuum coefficients, review their validation, and build a
  signed linear subtraction preview. Supply producer saturation ceilings or
  clipping masks; an unknown or skipped fit never falls back to manual weights.
  Optional Gaussian PSF preparation, explicit manual coefficients and saved
  exact-source plans are available under fit settings.
- Extract and stretch RGB stars from aligned linear original/starless images,
  restore them over a nebula, or screen an already prepared display stars layer
  without stretching it again. Star reduction stays linked across RGB.
- Preserve signed negative samples and NaN coverage in continuum residuals.
  Display results retain their transfer/provenance tags through FITS/XISF
  conversion and reopen with No Stretch. Saving uses the reviewed preview
  samples and leaves original sources unchanged.

Inputs must already share a registered grid and the required linear/display
scale. These tools do not perform star separation or another registration.
See [Color tools](https://github.com/theatrus/seiza-win/blob/v0.8.6/docs/COLOR-TOOLS.md)
for source contracts and saved-plan replay.

## Windows fixes

- Browse folders containing Windows `.lnk` shortcuts to supported image files,
  including recursive folder scans. Duplicate targets appear once; broken,
  corrupt, unsupported and folder shortcuts are skipped. Lookup does not invoke
  Shell Resolve or modify shortcuts.
- RC-Astro processing no longer opens unwanted console windows on Windows.
- Explorer previews and thumbnails preserve the colors of tagged display
  results instead of applying another stretch.

## Dependencies and validation

Published packages: Seiza/C ABI **0.44.2**, stacking **0.51.2**, parallax
**0.19.2**, satellites **0.22.2** and image-io **0.11.0**. Windows application
and native library versions remain independent.

Feature validation includes the managed and Windows graphics/codec suites,
native Rust suites, interactive color workflows and large-image solving.
Detailed scope, timings and limitations are in
[Windows validation](https://github.com/theatrus/seiza-win/blob/v0.8.6/docs/SEIZA-0442-VALIDATION.md)
and the [mosaic guide](https://github.com/theatrus/seiza-win/blob/v0.8.6/docs/MOSAIC-STACKING.md).

The production workflow verifies the signed application files both before and
inside the MSI, signs the installer as **StackFoundry LLC**, smoke-tests its
installation on a clean runner, and publishes the signed updater feed and
SHA-256 checksums.
