# Seiza for Windows 0.7.6

This point release fixes image thumbnails in the directory sidebar. It retains
the Seiza 0.19.0 core and stacking 0.20.0 from 0.7.5.

[Download the Windows x64 installer](https://github.com/theatrus/seiza-win/releases/download/v0.7.6/seiza-0.7.6-windows-x86_64.msi)
· [SHA-256 checksums](https://github.com/theatrus/seiza-win/releases/download/v0.7.6/SHA256SUMS.txt)

## Directory thumbnails

- Existing Auto MTF PNG previews now decode and display in the sidebar. The
  thumbnail-loading stream stays open until Windows has finished decoding,
  fixing a premature close that caused thumbnails to fail silently.
- Existing cached thumbnails work after updating; there is no need to clear
  the cache or regenerate previews.
- Source images, thumbnail stretch settings, processing defaults, and stacking
  behavior are unchanged.

## Distribution

The x64 MSI and its first-party binaries are Authenticode signed by
**StackFoundry LLC**. The in-app updater verifies both the signed update feed
and the installer signature in that feed.
