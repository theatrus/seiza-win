# Seiza for Windows 0.9.7

AI Models uses the image open in Seiza's browser. Reopening the dialog while
model setup or another operation is running now remembers the latest image
and selects it when the operation finishes, instead of silently ignoring it.

The dialog clearly labels the current image. **Change image…** is optional;
you can go straight to **Preview center** or **Save full FITS…** for a linear
FITS/XISF stack. Other browser formats remain visible with an explanation that
the noise model requires linear FITS/XISF input.

Switching images clears the previous comparison and saved-image shortcut.
Uses the same Seiza/C ABI 0.55.0 and bundled DirectML runtime as 0.9.6.
