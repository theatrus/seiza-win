# Seiza for Windows 0.9.1

This release adds graded per-light calibration, flat inspection, consistent
filter grouping, and source-pixel reads for large images. It brings the
calibration workflow into parity with Seiza for Mac PR #92 and adopts the
published Seiza 0.48.0 image I/O APIs.

## Review calibration before stacking

- Stack setup uses a resizable window with **Inputs**, **Calibration**,
  **Processing**, and **Review** tabs.
- Provide individual calibration files, a recursive library folder, or both.
  Mixed collections identify lights and calibration frames from native headers;
  unreadable files and other masters are reported separately.
- Grade frames, inspect per-light matches and master recipes, review flat
  groups, and choose automatic matching or one compatible set independently
  for flats and darks. Native matching/grading settings support per-rig values.
- Choose **Stop and review**, **Keep with available calibration**, or
  **Exclude from stack** for incomplete lights. Changing that execution choice
  keeps the current review.
- Each light receives its own calibration session on fixed and expanded
  canvases, including reference fallback, corrected flats, accepted pedestals,
  normalized XISF data, and transient-removal replay. Source files and historical
  masters are revalidated and protected from output replacement.
- Setup preferences remain local until stacking starts. Canceling setup or
  the output picker preserves saved defaults.

These changes apply to **Stack Images**. Live acquisition retains its existing
calibration preparation workflow.

## Inspect flats and source pixels

Use **Inspect Flat** on a source identified as a flat to measure its linear
median/channel levels, clipping, noise, illumination, dust geometry and
vignetting. Saturation and optional optical geometry are adjustable. Processed
or master flats show measurements without a raw-exposure grade. Single-frame
inspection does not establish set stability or association with lights.

Open Inspector with **Ctrl+Alt+I** and enable **Show source values under pointer**
to read source pixels before display processing. Bounded window reads avoid
decoding an entire mosaic. FITS scaling is applied, normalized XISF remains in
its stored units, and RGB channels retain their order. The existing stretch
symmetry picker continues to sample displayed luminance.

Window reads refuse unsupported compressed, complex or CIELab XISF instead of
falling back to a full-image decode. They do not verify a whole data-block
checksum. FITS HISTORY and COMMENT entries appear in Inspector's searchable
header list; shared header reads include supported PixInsight XISF WCS.

## Consistent filter grouping

Browser groups and batch/sky-field outputs now prefer the image's **FILTER**
header, falling back to filename detection when it is missing or blank, as
live stacking does. A misleading filename no longer overrides a supplied
filter header. Browser header discovery runs in the background and discards
results for a superseded collection.

## Validation and dependencies

0.9.1 is the first published Windows 0.9 release. The 0.9.0 workflow stopped
before publication when MSVC hit its Debug-symbol PDB size limit. Production
native checks now use the same Release profile as CI and the shipped DLLs.

Validation includes **868 managed tests**, **1,019 native tests** (six existing
ignored cases), **96 Windows graphics/codec tests** (four optional-input skips),
Rust formatting/Clippy, and installer build/action checks. Windows regressions
cover a small read at the far edge of a sparse **40,000 by 40,000** float FITS
image, XISF scaling and WCS, header cache invalidation, conflicting filter names,
and junction-based calibration discovery/source protection. Arc A770M tests
cover actual Vulkan and D3D12 computation with fixed/expanded calibrated
integration and replay against CPU results. These are correctness tests, not
real-observation performance benchmarks or a repeat of the full iGPU/dedicated
memory-cap matrix.

Native dependencies come from crates.io: Seiza/C ABI **0.48.0**, image-io
**0.12.0**, FITS **0.7.0**, XISF **0.8.0**, stacking **0.55.0**, calibration
**0.11.0**, and parallax **0.19.6**. No Git dependency remains. Native fixture
staging verifies the calibration archive locked by the published C ABI, even
when the unchanged calibration crate came from an earlier source revision.

The production workflow signs the application and installer as **StackFoundry
LLC**, verifies the packaged signatures, smoke-tests installation and launch,
and publishes the signed updater feed with SHA-256 checksums.
