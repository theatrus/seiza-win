# Seiza for Windows 0.8.8

This release brings image-list import and mosaic stacking into parity with
Seiza for Mac PR #91. It makes saved image selections easier to open and review,
puts the canvas choice first, and removes the 512-light sky-analysis limit.

## Open and review image lists

- Open TXT/CSV lists through regular **Open**, the welcome screen, drag/drop,
  command-line activation, or **Open image list** (Ctrl+Alt+O).
- Lists initially group images by source directory without changing your saved
  grouping preference. Choose **None** to restore the original file order.
  The initial image and window title follow the first displayed group.
- Expand **Skipped entries** to see the complete list path, physical source
  line, listed value and failure reason. Quoted multiline CSV fields retain
  accurate line numbers.
- Windows shortcuts and aliases to the same file appear once. Read-access
  failures are reported for the affected image.
- UTF-8 and BOM-marked UTF-16 lists are supported. Invalid encodings or malformed
  CSV quoting produce an error without publishing a partial collection.
  Relative paths, path-column aliases, SubframeSelector preambles and inclusion
  regardless of the Approved flag remain supported.

## Choose the stacking mode first

**Stacking mode** and the expanded-canvas memory ceiling now appear at the top
of the dialog. Expanded mosaics work directly from selected lights, including
images in different folders; they do not require prior solving or catalogs.
Star registration decides which lights join the output.

**Optional sky-panel analysis** is collapsed by default. Enable it to solve
lights, review pointings and separate unrelated sky fields. Analysis retains
your selected Fixed reference or Expanded mode and your overlap setting.

Expanded canvases cannot use a shared fixed alignment image. Choosing a new
one is disabled, and an existing choice can be cleared to restore readiness.
Calibration labels clarify that panels and folders within one output share
one compatible calibration set.

## Larger sky-panel selections

Sky analysis accepts more than 512 lights. Footprint comparisons use bounded
native batches with cancellation checks during preparation, between batches
and during grouping. The full overlap matrix still uses time and memory
proportional to the square of the solved-light count. Canvas limits and
per-output validation remain in effect.

See the [mosaic guide](https://github.com/theatrus/seiza-win/blob/v0.8.8/docs/MOSAIC-STACKING.md)
and [behavior comparison](https://github.com/theatrus/seiza-win/blob/v0.8.8/docs/MAC-PR-91-PARITY.md)
for screenshots and validation details.

## Validation and dependencies

Validation includes **831 managed tests**, **96 Windows graphics/codec tests**
(four optional-input skips), the full native suites, Rust formatting and clippy,
and installer build/action checks. A complete 513-light native footprint matrix
retained all frames and separated two sky fields. Interactive Windows checks
covered list grouping/order and diagnostics, opening 513 lights, direct expanded
readiness, optional analysis, actual solving/grouping of two M31 image copies,
retaining Fixed reference, and clearing incompatible shared alignment.
These synthetic/copy fixtures validate workflow behavior, not a 513-exposure
integration benchmark.

Native dependencies are unchanged: Seiza/C ABI **0.44.2**, stacking **0.51.2**,
parallax **0.19.2**, satellites **0.22.2** and image-io **0.11.0**.
The production workflow signs the application and installer as **StackFoundry
LLC**, verifies the packaged signatures, smoke-tests installation and launch,
and publishes the signed updater feed with SHA-256 checksums.
