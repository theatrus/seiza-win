# Seiza for Windows 0.9.4

Seiza 0.50 improves calibration, stacking and image reading in the existing
Windows tools.

- Dark master construction rejects outliers across exposures more robustly.
  Calibration matching prefers usable raw flats when an external flat master
  is older than the configured limit.
- Stacking scales photometric apertures with seeing and reduces the effect of
  stars on local background estimates.
- FITS reading validates compressed tiles and skips unrelated tiles when
  reading a region. XISF reading bounds XML nesting and rejects unfinished
  headers. Compressed downloads are checked for completeness.
- Stack exports protect source exposures and calibration masters even when an
  output filename is a hard link to an input.

This release uses Seiza/C ABI 0.50.0, stacking 0.58.0, calibration 0.12.2,
FITS 0.8.1, XISF 0.9.1, image I/O 0.13.1 and parallax 0.20.1. The installer is
self-contained and works without a separate Visual C++ Redistributable.
