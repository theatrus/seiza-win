# Seiza for Windows 0.7.4

This point release removes satellite and aircraft trails that stacking used to
keep. It moves to the published Seiza 0.18.18 core.

[Download the Windows x64 installer](https://github.com/theatrus/seiza-win/releases/download/v0.7.4/seiza-0.7.4-windows-x86_64.msi)
· [SHA-256 checksums](https://github.com/theatrus/seiza-win/releases/download/v0.7.4/SHA256SUMS.txt)

## Remove transients after stacking

- Stacking rejects outliers as frames arrive. The first frame and the first few
  after it go in before there is anything to compare them with, so a satellite
  or aircraft trail in one of them stayed in the finished stack.
- **Remove transients after stacking**, on by default in the directory and
  live stacking windows, fixes that. When the stack is done, Seiza reads every
  accepted frame twice more, prepares it exactly as before, and rejects any
  sample that stands out from the other frames, the first frames included. It
  uses the stack's sigma limits. Star detection and registration do not run
  again.
- Directory stacking shows each pass and frame, and Cancel stops the step.
  Live stacking shows the same in its status line when you finish.
- When a stack cannot be replayed, for example a live session resumed from a
  checkpoint saved by an older Seiza or a source file that changed since it was
  stacked, Seiza writes the normal stack and says why.

## Core and distribution

- Bundle the published Seiza 0.18.18 C ABI.
- The x64 MSI and its first-party binaries are Authenticode signed by
  **StackFoundry LLC**. The in-app updater verifies both the signed update feed
  and the installer signature in that feed.
