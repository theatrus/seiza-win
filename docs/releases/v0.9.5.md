# Seiza for Windows 0.9.5

Restore linear FITS and XISF stacks with Seiza noise models from **AI Models…**
in the toolbar's **More options** menu. The recommended model downloads and
installs automatically. Installed models work offline; **Advanced processing**
lets you check for updates, choose another model, or import a local bundle.

**Preview center** processes only the center crop, up to 768 × 768 pixels.
Adjust **Grain reduction** and **Mottle reduction**, then use **Update preview**
to blend the cached result. Original and restored views share one display
stretch. **Save full FITS…** processes the full image and retains WCS and model
provenance. Saving is available before a preview, and source files are protected.

The bundled ONNX Runtime enables DirectML on compatible Windows GPUs. Automatic
selection uses DirectML when the model supports it. Advanced controls include
an explicit DXGI adapter index, precision, tile size, and grain/mottle scale.
DirectML inference was validated on Intel Iris Xe and Arc A770M.

Image commands live in the existing toolbar. Seiza icons appear in native
window titles and in-app dialogs. New stacks default to Quadratic registration;
existing Similarity settings remain supported.

Uses Seiza/C ABI 0.53.0 and its shared model catalog, restoration, preview, and
export APIs. The installer is self-contained and works without a separate
Visual C++ Redistributable.
