# Seiza for Windows 0.1.2

The first update-capable Seiza for Windows release.

## Changes

- Added automatic update checks after startup, with an opt-out in Settings.
- Added **Check for updates** to the **More** menu and **Check now** to
  Settings.
- Added native WinUI dialogs for update availability, release notes, download
  progress, cancellation, skipped versions, and actionable failures.
- Added strict Ed25519 verification of both the Sparkle appcast and downloaded
  MSI before installation.
- Added a tag-driven release pipeline that builds and smoke-tests the all-users
  installer, produces the signed Sparkle feed, publishes SHA-256 checksums, and
  creates the GitHub release.

This release establishes the signed Windows update feed. Install 0.1.2 once
from GitHub; the next release will be the first one offered and installed
through Seiza's in-app updater.

## Install

Download `seiza-0.1.2-windows-x86_64.msi` and compare it with the value in
`SHA256SUMS.txt`. The installer requires Windows 11 24H2 or newer on x64 and
administrator approval because it installs for every user.

This preview is not yet Authenticode-signed, so Windows may display an
unknown-publisher warning. Sparkle's Ed25519 signatures independently protect
the update feed and downloaded installer. The MSI includes .NET 10, Windows
App SDK/WinUI, Win2D, and the Seiza Rust core; it does not download another
runtime during installation or first launch.

## Still in progress

Multiple document windows, 16-bit PNG/TIFF export, Explorer Preview/thumbnail
integration, ARM64, and production code signing remain planned work.
